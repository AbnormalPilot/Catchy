# Catchy — Technical Spec

> Stack and platform come from the learner's brief ("native macOS menu bar app (SwiftUI, Xcode) … Vision … Apple's on-device Foundation Models … EventKit"). Implementation details below were derived by the agent from those choices; consequential ones are listed under **Decisions and Open Issues**.

## How This Works, In Plain Language
Catchy is one small Mac app that lives in the menu bar. It has four parts:

1. **Ears:** a clipboard watcher, a global hotkey, and a right-click Services entry. They notice that you caught something.
2. **Eyes:** Apple's Vision framework turns screenshots and photos into text, on the Mac.
3. **Brain:** Apple's on-device language model (Foundation Models) reads the text and fills in a structured form: what, when, where, which time zone, and event or task. Apple's built-in date detector gives it already-resolved dates to lean on, and takes over if Apple Intelligence is off.
4. **Hands:** EventKit writes the result into Calendar or Reminders. iCloud then syncs it to the iPhone and Watch, so Catchy needs no server and no account.

The notch island shows a card between the brain and the hands, so the user always confirms before anything is saved. Nothing is sent anywhere. That's why everything is an Apple framework running locally rather than a cloud API.

## The Core Journey Through the System
PRD ref: `prd.md > The Core Journey`.

1. The user copies text → `ClipboardWatcher` sees the change count move → asks the system whether the clipboard holds a calendar event (without reading it) → reads the text → `AppState.catchText`.
   - If an image was copied instead → `ScreenReader.recognizeText(in:)` → text → same path.
   - ⌥⌘ tap → `ModifierTapHotKey` → `RegionSelector` overlay → `ScreenReader.readText(in:)` → text → same path.
   - Services menu → `ServiceProvider.catchText` → same path.
2. `AppState` opens the island (compact) in **Reading**, then calls `EventExtractor.extract`. That step builds `DateHints`, prompts the model for a `GeneratedCatch`, and converts each item into an `EventDraft`, applying the time zone.
3. One draft → `EventCardView`. Several drafts → `CatchListView`. None → **Nothing found**.
4. The user clicks Add → `CalendarService` asks for access if needed → saves an `EKEvent` or `EKReminder` → returns a `SavedCatch` with the saved identifiers (for Undo).
5. **Saved** view → iCloud syncs to the iPhone (outside Catchy).

## Stack
- Swift 6, SwiftUI + AppKit, macOS 26 (Tahoe) SDK, Xcode 26. Learner's brief.
- **Foundation Models** (on-device LLM, guided generation with `@Generable`): https://developer.apple.com/documentation/foundationmodels
- **Vision** `RecognizeTextRequest` (OCR): https://developer.apple.com/documentation/vision/recognizetextrequest
- **ScreenCaptureKit** `SCScreenshotManager.captureImage(in:)`: https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager
- **EventKit** (Calendar + Reminders): https://developer.apple.com/documentation/eventkit
- **NSPasteboard detection** `detectedPatterns(for:)` (macOS 15.4+): https://developer.apple.com/documentation/appkit/nspasteboard
- **ServiceManagement** `SMAppService` (Launch at Login): https://developer.apple.com/documentation/servicemanagement/smappservice
- A listen-only `CGEventTap` for the modifier-only ⌥⌘ tap (Carbon hot keys need a letter key). Needs Input Monitoring (`CGRequestListenEventAccess`).
- XcodeGen (`project.yml` → `Catchy.xcodeproj`): https://github.com/yonaskolb/XcodeGen
- No third-party packages. The built-in `MenuBarExtra` can't be opened from code, so an `NSStatusItem` + `NSPopover` is used instead of FluidMenuBarExtra (which the learner's brief allowed as a fallback).

## Where It Runs and How Someone Tries It
- Requirements: a Mac on macOS 26 with Apple Silicon; Apple Intelligence turned on for the AI path (otherwise basic detection runs); Xcode 26.

  `xcodebuild -project Catchy.xcodeproj -scheme Catchy -configuration Debug -derivedDataPath build build && open build/Build/Products/Debug/Catchy.app`

## Components

### StatusItemController
The menu bar icon; it toggles the island.

### IslandController + IslandPanel + IslandView
A borderless, non-activating `NSPanel` above the menu bar, centred on the notch (from `NSScreen.auxiliaryTopLeftArea`/`auxiliaryTopRightArea` and `safeAreaInsets.top`). `IslandView` springs a black `NotchShape` from notch size to the content's size; compact while reading. The window grows immediately and shrinks after the animation. Outside clicks (global mouse monitor) and Esc close it. The ••• menu (Pause, Launch at Login, Quit) lives in its header.
PRD ref: `prd.md > Screens and Layout`, `prd.md > Welcome and login`.

### ClipboardWatcher
Polls `changeCount` every 0.6 s. For text, it gates on `detectedPatterns(for: [\.calendarEvents])`. For images (with no text on the clipboard), it OCRs them and continues only if `DateHints` finds a date. It skips concealed/transient types, repeats of the same text, and anything while Pause is on.
PRD ref: `prd.md > Clipboard catching`, `prd.md > Image catching`.

### ModifierTapHotKey + RegionSelector + ScreenReader
⌥⌘ tap → overlay windows on every screen → a rect in AppKit coordinates → flipped to display space → screenshot → Vision text.
PRD ref: `prd.md > Screen capture`.

### ServiceProvider
`NSApp.servicesProvider`. The `catchText` message is declared under `NSServices` in Info.plist, with the menu item "Catch with Catchy" and send type plain text.
PRD ref: `prd.md > Services menu`.

### EventExtractor + DateHints
`@Generable GeneratedCatch { items: [GeneratedItem] }`, with at most 8 items. Each `GeneratedItem` has:
- `kind` (event | task)
- `title`
- `startDate` / `startTime` / `endDate` / `endTime`
- `timeZone` (as written in the text, or empty)
- `location`
- `notes`

Generation uses greedy sampling and a fresh, prewarmed session per catch. `DateHints` (NSDataDetector) resolves relative dates, merges split date/time phrases, and reads detected time zones. It is passed into the prompt as anchors, and it is the whole extractor when the model is unavailable.

Time zones resolve through a small abbreviation table (ET, CT, MT, PT, GMT/UTC, BST, CET, IST, JST, AEST, SGT and others), then `TimeZone(abbreviation:)`, then `TimeZone(identifier:)`. Dates are built in the source zone, and EventKit stores the absolute time.
PRD ref: `prd.md > Understanding the text`.

### AppState
An `@Observable` phase machine:

`idle | reading | review | nothingFound | needsScreenAccess | saved | failed`

It holds `drafts: [EventDraft]`, `selection` (the index being edited), and the last `SavedCatch` for Undo.
PRD ref: `prd.md > The Core Journey`.

### CalendarService
Access, save, clash lookup and undo, for both events and reminders:
- **Access:** `requestFullAccessToEvents` / `requestFullAccessToReminders`.
- **Clash lookup:** `predicateForEvents(withStart:end:calendars:)`; the first non-all-day overlap wins.
- **Undo:** `remove(_:span:)` using the saved identifiers.

PRD ref: `prd.md > Saving and Undo`, `prd.md > The card`.

### Views
- `IslandContent`: routes by state, plus the welcome/idle view.
- `EventCardView`: one event or task.
- `CatchListView`: several catches with checkboxes.
- `SavedView`, `ScreenAccessView`, `MessageView`.

PRD ref: `prd.md > Screens and Layout`.

## Data Model
`EventDraft`:
- kind
- title
- start, end, isAllDay
- location, notes, url
- `sourceTimeZone: TimeZone?` (shown on the card only when it differs from local)
- `isIncluded` (for the list)

All in memory, gone when the island resets. `UserDefaults` holds only:
- `selectedCalendarID`
- `selectedReminderListID`
- `pauseCatching`
- `hasSeenWelcome`

Launch at Login state is read from `SMAppService.mainApp.status`. No history is stored (cut).

## External Services and Dependencies
None over the network. Everything above is an on-device Apple framework. There are no keys, no rate limits and no cost.

## Important Failure Modes
- **Apple Intelligence off or the model still downloading** → `DateHints` fills the card, and a note explains why.
- **Permission denied (Calendar/Reminders/Screen Recording)** → a banner or explainer with a button to the exact System Settings pane. Screen Recording also offers Reopen.
- **The model misreads the date** → the card is always editable before saving, the original text is one click away, and Undo is there after saving.

## What Was Simplified and Why
- **Polling the clipboard** instead of a change notification: macOS has no clipboard notification.
- **No settings screen:** the ••• menu holds the two toggles, and last-used choices are remembered.
- **A curated time-zone table** instead of full natural-language zone parsing: it covers the common written forms, and the model normalises the rest to an abbreviation or an IANA name.
